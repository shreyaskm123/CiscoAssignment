# Telemetry Helm charts

Umbrella chart that deploys the GPU-telemetry pipeline:

```
streamer ──publish──> MQ leader ──replicate──> MQ replicas ──consume──> collector ──write──> ClickHouse ──read──> apiGateway
```

**Do not follow the old leader/follower StatefulSet names.** MQ is one
StatefulSet (`telemetry-messagequeue`) with Lease-based election. The supported
install path is:

```bash
./scripts/quickstart.sh --tag v1.0.0
```

Full walkthrough, API examples, and troubleshooting: [`docs/quickstart.md`](../docs/quickstart.md).
Operations: [`docs/operations.md`](../docs/operations.md).

## Layout

```
helm-charts/
├── telemetry/                  # umbrella chart
│   ├── Chart.yaml              # deps: messagequeue, streamer, collector, clickhouse, apigateway
│   ├── values.yaml             # per-subchart defaults
│   ├── values-prod.yaml        # auth Secrets + NetworkPolicies (machine-independent)
│   └── charts/
│       ├── messagequeue/       # 2-replica StatefulSet, Lease election, -sync-replicas acks
│       ├── streamer/           # Deployment, metrics.csv ConfigMap
│       ├── collector/          # Deployment, ClickHouse sink
│       ├── clickhouse/         # 2 replicas + 3-member Keeper (replicated)
│       └── apigateway/         # Deployment + ClusterIP :8080
```

Install always uses **two** values files:

```bash
helm upgrade --install telemetry ./helm-charts/telemetry -n telemetry \
  -f ./helm-charts/telemetry/values-prod.yaml \
  -f ./dist/values-local.yaml --wait
```

`dist/values-local.yaml` is generated by `scripts/kind-up.sh` and supplies the
image tags (`pullPolicy: Never`) plus the kind API-server CIDR. Omitting it
reverts images to unbuilt `latest` and breaks leader election.

## Replication

One StatefulSet, default 2 replicas. A Kubernetes Lease `mq-leader` elects
exactly one leader; the rest are replicas. The leader acks a publish only after
`sync-replicas` followers have durably applied it. Failover is automatic — do
not delete pods named `*-leader-0` / `*-follower-0`; those names no longer exist.

## Scale

```bash
helm upgrade telemetry ./helm-charts/telemetry -n telemetry \
  -f ./helm-charts/telemetry/values-prod.yaml \
  -f ./dist/values-local.yaml \
  --set messagequeue.replicas=3 \
  --set streamer.replicas=4 \
  --set collector.replicas=2
```

## Teardown

```bash
./scripts/kind-up.sh --down
```
